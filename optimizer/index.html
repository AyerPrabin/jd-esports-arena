JD-Optimiers

FPS booster, mouse tuner and panel scanner for Free Fire on MSI App Player / BlueStacks 5. One button: it optimizes Windows, opens the game and boosts until you close it.

Install

  1. Download the zip above and extract it (right-click → Extract all). Keep the folder anywhere, e.g. Documents.
  2. Open JD-Optimiers.exe. Windows SmartScreen may say “Windows protected your PC” because the app is new and not code-signed — click More info → Run anyway.
  3. Accept the Administrator prompt (needed for power plan, GPU settings and live FPS).
  4. Close MSI App Player, press Apply best profile, then Play Free Fire.
Updates are automatic and required. When a new version is posted here, the app shows a pop-up at start and updates itself in a few seconds (the download is checked with SHA-256 before it replaces anything). It only checks when the app starts.

What it does

Boost

Ultimate power plan, Game Mode, background apps paused while you play, emulator on the graphics card at high priority.

Graphics

High FPS on, VSync off, dedicated GPU, GPU scheduling — and 1080p on high-end PCs. Every change can be undone with Restore all.

Mouse

Sensitivity presets, pointer acceleration off for steady aim, aim key position check.

Panel scan

Looks for known cheat panels on the PC and reports them. Detect-only — it never deletes anything.

Account-safe by design: JD-Optimiers changes Windows settings, the emulator's settings file and — only when you press Aim fix or remove macros — its key-mapping file, always with a backup. It never reads or edits the game's memory, never injects anything, and adds no macros or aim assist.
