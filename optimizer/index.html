Install

  1. Download the zip above and extract it (right-click → Extract all). Keep the folder anywhere, e.g. Documents.
  2. Open JD-Optimiers.exe. Windows SmartScreen may say “Windows protected your PC” because the app is new and not code-signed — click More info → Run anyway.
  3. Accept the Administrator prompt (needed for power plan, GPU settings and live FPS).
  4. The app shows a code like ABCD-2345 and opens this site. Check the code matches, then press Link this PC. The app opens by itself.
  5. Close MSI App Player, press Apply best profile, then Play Free Fire.
Updates are automatic and required. When a new version is posted here, the app shows a pop-up at start and updates itself in a few seconds (the download is checked with SHA-256 before it replaces anything). It only checks when the app starts.

Questions

Will it get my game account banned?

No. JD-Optimiers only changes Windows and the emulator's own settings — the same things you could change by hand. It never touches the game's memory, never injects anything, and adds no macros or aim assist. Everything it changes can be undone with "Restore all".

Does it work on a weak PC or laptop?

Yes. It detects your hardware and tunes itself — strong PCs get the full treatment (1080p, GPU scheduling), weak PCs get Potato mode (lowest graphics, highest FPS). It works on any Windows 10/11 PC or laptop.

Can I use it for games other than Free Fire?

Yes. Add any game's .exe, or leave auto-detect on and any full-screen PC game is boosted automatically — Steam, Epic, Riot, anything.

How do I pay?

With JD points (1 point = Rs 1). Load points on your wallet with eSewa, then buy a plan here. Pro is 49 points, Max is 99 points for 30 days.

How many PCs can I use it on?

Two at a time per account (up to 4 new links in 30 days). You sign in once per PC with a code — no password is typed into the app.

Do plans renew automatically?

No. A plan lasts 30 days and simply ends — you buy again when you want. Buying again adds 30 days; upgrading Pro → Max keeps the days you already paid for.

Can I get a refund?

Points aren't refunded once a plan starts, except where the law requires it or the app never worked for you because of a fault on our side — see the JD-Optimiers terms.
