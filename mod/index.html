How it works

Match night

Pick tonight's event. In Squads, set Playing to Yes for squads that confirmed. Tap WhatsApp to send a ready reminder to the ones that haven't. Remove squads that never confirm – the waitlist moves up by itself.

Room code

Type the Room ID and password and send it about 5 minutes before the start. Only squads in a slot get it. If you remove a squad after sending, change the room password and send the new one.

Host mods

Invited scrim hosts see only the events the JD admin made them host of. Message on a squad sends its captain a notification. Chats and prize payouts stay with the JD team.

Chats

JD team only. Tap Message on a squad, or type a player's @username, to chat with them. They see it in Messages as JD Esports with a verified tick – never your name or email – and get a phone push. Their replies show up here with a count on the Chats tab. This chat is people only: ZULU's automatic messages go to the player's ZULU chat.

Notifications

Templates fill the title and message. Notifications go only to the squads in the event you picked, never to everyone on JD Arena.

Results and prizes

In Results, type each squad's points per match. Publish standings after each match so the leaderboard updates. After the last match, Finish & pay prizes: it sets the winner, marks the event finished, saves the all-time leaderboard and pays the prizes into the winners' wallets. You can only pay registered squads, never more than the prize pool, and each squad once. Every payment is logged for the admin.

Points

1 point = Rs 1. Players load points on their Wallet with the eSewa QR and a screenshot; the admin adds them. Paid events need enough points to join. Apart from prizes, only the admin changes balances, bans or events.
